# Product Document - Adventure Log

## 📋 프로젝트 개요

**프로젝트명**: Adventure Log (맛집 어드벤처 로그)
**버전**: 0.1.0 (Phase 1 개발 중)
**유형**: 개인/소그룹용 웹 애플리케이션
**목적**: 흩어진 맛집/카페/명소 정보를 체계적으로 관리하고 우선순위 기반 방문 계획 수립

## 🎯 미션 & 비전

### 미션 (MISSION)
인스타그램, 블로그, 카톡 등에 흩어져 있는 맛집 정보를 한 곳에서 체계적으로 관리하여 효율적인 방문 계획을 세우고 소중한 추억을 기록할 수 있는 플랫폼 제공

### 비전 (VISION)
가족과 친구들이 함께 맛집 탐방의 즐거움을 계획하고 공유하며 기록할 수 있는 최고의 개인 맛집 관리 도구

## 👥 핵심 사용자 (USER)

### 주요 페르소나
1. **가족/친구 그룹**
   - 소규모 그룹(2-10명)이 함께 사용
   - 맛집 정보를 서로 공유하고 함께 방문 계획 수립
   - 공동의 추억과 경험 기록

### 사용 시나리오
- **정보 수집**: 인스타그램이나 블로그에서 발견한 맛집을 Quick Save로 빠르게 저장
- **계획 수립**: 우선순위와 지역별로 정리된 정보를 바탕으로 주말 방문 계획 수립
- **경험 기록**: 방문 후 사진과 메모로 경험 기록, 별점 평가
- **정보 공유**: 가족/친구와 맛집 정보 및 경험 공유

## 🔑 핵심 기능 (FEATURES)

### Phase 1 (현재 개발 중)
- ✅ **Google OAuth 로그인**: 간편한 소셜 로그인
- ✅ **장소 CRUD**: 장소 정보 생성/조회/수정/삭제
- ✅ **Quick Save**: URL만으로 빠른 장소 저장
- ✅ **스마트 필터링**: 카테고리, 지역, 방문상태, 우선순위별 필터
- ✅ **검색 기능**: 이름, 키워드 기반 검색
- ✅ **우선순위 대시보드**: 방문 우선순위 기반 시각화
- ✅ **이미지 관리**: 장소별 이미지 업로드 및 관리

### Phase 2 (계획)
- ⬜ **휴지통 시스템**: 삭제 항목 복구 기능
- ⬜ **실시간 영업 정보**: 영업 중/마감 상태 표시
- ⬜ **지도 뷰**: 장소를 지도에서 한눈에 확인
- ⬜ **갤러리 뷰**: 이미지 중심 탐색
- ⬜ **캘린더 뷰**: 방문 일정 관리

## 🚨 해결하고자 하는 문제 (PROBLEM)

1. **정보 분산 문제**
   - 현황: 맛집 정보가 카톡, 인스타, 메모장 등에 흩어져 있음
   - 해결: 중앙화된 단일 플랫폼에서 모든 정보 관리

2. **정보 유실 문제**
   - 현황: 시간이 지나면 저장한 정보를 찾기 어려움
   - 해결: 체계적인 카테고리와 태그 시스템으로 영구 보관

3. **계획 수립 어려움**
   - 현황: 어디를 먼저 가야할지 우선순위 결정 어려움
   - 해결: 우선순위 시스템과 지역별 그룹화로 효율적 계획

4. **경험 기록 부재**
   - 현황: 방문 후 기억과 경험이 흐려짐
   - 해결: 사진과 메모로 상세한 경험 기록

## 🏆 차별화 요소 (DIFFERENTIATION)

1. **무료 & 오픈소스**
   - Supabase 무료 티어로 운영 비용 제로
   - 완전한 데이터 소유권 보장

2. **우선순위 중심 설계**
   - 단순 저장이 아닌 방문 계획 중심
   - 스마트한 우선순위 관리 시스템

3. **Quick Save 기능**
   - 복잡한 입력 없이 URL만으로 즉시 저장
   - 나중에 천천히 상세 정보 보완 가능

4. **가족/친구 최적화**
   - 소규모 그룹 공유에 최적화
   - 프라이빗한 환경에서 안전한 정보 공유
