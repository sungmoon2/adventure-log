## 🎯 미션과 비전

### 미션
흩어진 맛집 정보를 한 곳에서 체계적으로 관리하고, 우선순위 기반으로 효율적인 맛집 탐방을 지원하는 개인 맞춤형 관리 시스템

### 비전
모든 맛집 애호가들이 자신만의 맛집 지도를 만들고, 계획적이고 즐거운 미식 여행을 즐길 수 있는 최고의 개인 도구가 되는 것

## 👤 핵심 사용자 및 페르소나

### 주요 타겟: 일반 개인 사용자

**페르소나 1: 맛집 수집가 민수 (28세, 직장인)**
- 인스타그램과 블로그에서 맛집 정보를 자주 발견
- 스크린샷과 북마크로 저장하지만 정리가 안 됨
- 주말마다 어디를 갈지 고민하는 시간이 김
- 방문 후기를 기록하고 싶지만 체계적인 도구 부재

**사용 시나리오**:
1. 인스타그램에서 맛집 발견 → Quick Save로 빠르게 저장
2. 주말 계획 시 우선순위 높은 맛집 확인
3. 방문 후 사진과 메모 추가하여 개인 리뷰 작성
4. 친구 만날 때 지역/카테고리별로 빠르게 검색

## 🔍 해결하고자 하는 핵심 문제

### 1. 정보 분산 문제 (Priority: HIGH)
- **현재 상황**: 인스타그램, 네이버, 카카오맵 등 여러 플랫폼에 저장
- **문제점**: 필요할 때 찾기 어렵고, 중복 저장 발생
- **해결책**: 통합 관리 플랫폼으로 모든 정보 일원화

### 2. 체계적 관리 부재 (Priority: HIGH)
- **현재 상황**: 단순 북마크/스크린샷만 저장
- **문제점**: 카테고리, 지역, 우선순위 등 분류 불가
- **해결책**: 구조화된 데이터베이스와 필터링 기능

### 3. 우선순위 설정 어려움 (Priority: HIGH)
- **현재 상황**: 저장된 맛집이 많아질수록 선택 장애 발생
- **문제점**: 어디부터 가야 할지 결정하기 어려움
- **해결책**: 5단계 우선순위 시스템과 대시보드 뷰

### 4. 메모/후기 관리 (Priority: MEDIUM)
- **현재 상황**: 방문 후 기억이 희미해짐
- **문제점**: 개인적인 평가와 메모를 남길 곳 없음
- **해결책**: 방문 기록, 사진 업로드, 개인 메모 기능

## 🚀 핵심 기능 및 특징

### Phase 1 (현재 개발 중)
1. **Google OAuth 인증**
   - 간편한 로그인/로그아웃
   - 개인 데이터 보호

2. **장소 관리 (CRUD)**
   - 장소 추가/조회/수정/삭제
   - 이름, 카테고리, 지역, URL, 메모 입력
   - 우선순위 설정 (1-5단계)

3. **Quick Save**
   - 최소 정보로 빠른 저장
   - 나중에 상세 정보 추가 가능

4. **스마트 필터링**
   - 카테고리별 (카페, 한식, 일식 등)
   - 지역별 (강남, 홍대, 성수 등)
   - 방문 상태별 (미방문/방문완료)
   - 우선순위별 필터

5. **검색 기능**
   - 장소명 검색
   - 키워드/태그 검색

6. **대시보드**
   - 우선순위 기반 추천
   - 미방문 장소 하이라이트
   - 통계 정보 제공

7. **이미지 관리**
   - 장소별 사진 업로드
   - 갤러리 뷰

### Phase 2 (계획)
1. **지도 연동**
   - 지도에서 위치 확인
   - 경로 안내
   - 근처 맛집 탐색

2. **AI 기반 추천**
   - 사용자 취향 학습
   - 맞춤형 맛집 추천
   - 유사 맛집 제안

3. **소셜 기능**
   - 친구와 리스트 공유
   - 공동 리스트 관리
   - 추천 시스템

4. **리뷰 분석**
   - 외부 리뷰 자동 수집
   - 핵심 키워드 추출
   - 평점 통합 관리
